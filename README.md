# Pigeon Service Mini

Посмотреть онлайн: [https://milyygg.github.io/pigeon-taplink/](https://milyygg.github.io/pigeon-taplink/)

Сделал мобильный мини-сайт частного мастера по ремонту техники: услуги, формат работы, фотографии ремонта, отзывы и контакты.

Демонстрационная версия дизайна. Основной сайт мастера: https://milyygg.github.io/pigeon-service/

## Запуск

Откройте `index.html` в браузере. Сборка и установка зависимостей не нужны.

- `index.html` - содержание и ссылки.
- `style.css` - адаптивное оформление.
- `script.js` - меню, галерея и просмотр фотографий.
- `assets/` - материалы Pigeon Service и локальный шрифт.

Отзывы перенесены из предоставленных скриншотов профиля Авито. Рейтинг и количество отзывов указаны по предоставленным данным на 17.10.2026. Фотографии и фирменные иллюстрации относятся к Pigeon Service и не предназначены для свободного использования в чужих проектах. Лицензия Manrope сохранена в `assets/font-license.txt`.

Заявки, персональные данные и платежи не собираются. Для постоянного коммерческого размещения нужен подходящий хостинг. Это самостоятельная HTML-страница, не шаблон для импорта в конструктор Taplink.
